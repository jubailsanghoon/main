홈 화면에 추가해 앱처럼 쓰기

스토어 설치 없이 스마트폰 홈 화면에 바로가기를 추가하면 오프라인 현장에서도 빠르게 열 수 있습니다.

Android Chrome

  1. 각 앱 페이지(heat.iskorea.org / wcl.iskorea.org)를 엽니다
  2. 우측 상단 메뉴에서 ‘홈 화면에 추가’ 또는 ‘앱 설치’를 누릅니다
  3. 바탕화면 아이콘으로 전체 화면 앱처럼 실행합니다

iOS Safari

  1. Safari에서 각 앱 페이지를 엽니다
  2. 하단 공유 버튼을 누르고 ‘홈 화면에 추가’를 선택합니다
  3. ‘추가’를 누르면 홈 화면에 아이콘이 생성됩니다

자주 묻는 질문 (FAQ)

앱 설치, 오프라인 사용, 데이터 저장 및 PRO 라이선스 안내
앱 스토어에서 별도로 설치하지 않아도 바로 쓸 수 있나요?

네. 모바일 브라우저에서 바로 실행되며, '홈 화면에 추가'를 해두면 일반 앱처럼 전체 화면으로 실행되고 네트워크가 불안정한 현장에서도 오프라인으로 동작합니다.

현장에서 입력한 계산 기록이나 작업 데이터는 외부 서버에 저장되나요?

아니요. 모든 계산 기록과 프리셋은 사용자의 스마트폰·PC 브라우저 내부(로컬 스토리지)에만 저장되며, 외부 서버로 전송되지 않습니다.

Free 버전과 PRO 버전의 차이는 무엇인가요?

현장에서 자주 쓰는 핵심 계산과 기본 기록·CSV 내보내기는 무료로 제공됩니다. PRO 버전은 특수 공정/보고서 PDF·Excel 출력, 대량 프리셋 관리, 안전 점검표 등 확장 기능을 지원합니다.

기기 고유번호(Device ID)로 PRO 인증은 어떻게 하나요? 기기를 바꾸면요?

각 앱 상단의 [Free] 배지를 눌러 기기 고유번호를 확인하고 성함·이메일 입력 후 후원을 완료하면 해당 기기에 영구 PRO가 활성화됩니다. 라이선스는 기기 1대(고유번호 1개) 기준으로 발급되므로, 기기를 변경하신 경우 새 기기에서 추가로 후원·인증을 진행해 주시기 바랍니다.

후원 확인이나 라이선스·기능 요청은 어디로 문의하나요?

후원 안내 섹션의 1:1 채팅 문의 버튼 또는 isksolution555@gmail.com으로 연락해 주시면 빠르게 확인해 드립니다.

찾는 답변이 없다면 카카오 1:1 채팅으로 바로 문의해 주세요.
